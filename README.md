# 🎬 Netflix Clone - HTML5 Semântico & CSS3

Um clone responsivo da interface da **Netflix**, desenvolvido do zero com foco em **HTML5 totalmente semântico (zero `<div>`s)**, acessibilidade, boas práticas de estruturação web e design moderno.

---

## 🚀 Diferenciais do Projeto

- **Zero `<div>`s**: Todo o layout e estruturação de telas foram construídos utilizando exclusivamente elementos semânticos do HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<figure>`, `<aside>`, `<footer>`, etc.).
- **Acessibilidade**: Uso estratégico de atributos ARIA (`aria-label`, `role`) e navegação por teclado amigável para leitores de tela.
- **Design Responsivo**: Adaptado para telas de smartphones, tablets e desktops usando Media Queries e layouts em Flexbox e CSS Grid.
- **Fidelidade Visual**: Interface fiel à identidade visual da Netflix, com foco na experiência do usuário (UX).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Semântica pura e estruturação acessível.
- **CSS3**: Layouts com Flexbox, CSS Grid, variáveis CSS, transições e animações suaves.
- **DiceBear API & Picsum**: Imagens dinâmicas para avatares de perfis e posters de filmes.

---

## 📂 Páginas do Projeto

1. **Seleção de Perfis (`profiles.html`)**: Tela inicial para escolha do perfil de usuário.
2. **Catálogo Principal (`home.html`)**: Destaque principal (banner) e carrosséis/listas de conteúdos categorizados.
3. **Detalhes do Conteúdo (`details.html`)**: Informações aprofundadas sobre filmes/séries, elenco, sinopse e recomendações relacionadas.
4. **Reprodutor de Vídeo (`watch.html`)**: Player customizado com controles interativos de reprodução.
